# CryptoWatch

**CryptoWatch** — это учебный проект, представляющий собой одностраничное приложение (SPA) для отслеживания курсов криптовалют в реальном времени.

Приложение демонстрирует, как создать быстрый и отзывчивый интерфейс для работы с данными из внешнего API без использования фронтенд-фреймворков.

## Особенности

*   **Данные в реальном времени**: Курсы криптовалют запрашиваются у публичного API [CoinGecko](https://www.coingecko.com/ru/api).
*   **Мгновенный поиск**: Фильтрация списка монет по названию или тикеру происходит на стороне клиента, без дополнительных запросов к серверу.
*   **Клиентская сортировка**: Возможность сортировать монеты по разным критериям (цена, рейтинг, изменение за 24 часа) без перезагрузки страницы.
*   **Адаптивный дизайн**: Интерфейс корректно отображается на разных устройствах.
*   **Чистый JavaScript**: Проект написан на ванильном JavaScript (ES6+), HTML и CSS, без использования сторонних библиотек и фреймворков.

## Техническая реализация

1.  **Загрузка данных**: При загрузке страницы скрипт один раз отправляет запрос к API CoinGecko для получения списка из 50 популярных криптовалют.
2.  **Источник правды**: Полученные данные сохраняются в массиве в памяти (`allCoins`). Этот массив служит единственным «источником правды» для всех последующих операций.
3.  **Фильтрация и сортировка**: Любые действия пользователя (ввод в поле поиска, выбор опции сортировки) не инициируют новых сетевых запросов. Вместо этого скрипт заново обрабатывает исходный массив `allCoins` и перерисовывает только ту часть DOM, которая должна измениться.

Такой подход обеспечивает максимальную скорость отклика интерфейса после первоначальной загрузки.

## Как запустить

Поскольку проект не требует сборки, его можно запустить, просто открыв файл `index.html` в любом современном браузере. Для корректной работы необходим доступ в интернет для загрузки данных от API.
